# Team-harness distribution manifest — the file list `/setup:teams` installs into a project.

# Format, one entry per line (blank lines and `#` comments ignored):
#   own <path>     a harness-only file: copied when absent, `conflict` when it differs locally
#   shared <path>  a file the project may already own (its own content wins): never overwritten
#   !<glob>        a path that must NOT appear as own/shared (checked by team-setup.sh)

# sync playbook (`.claude/starter-sync-playbook.md` → Category A); the harness tests are
# deliberately out of the distribution — a project runs the harness, it does not re-test it.
